
# First Project Flask

Project ini dibuat untuk memenuhi tugas praktikum Flask pada pertemuan 11.

## Deskripsi
Aplikasi web sederhana menggunakan Python Flask dengan fitur memasukkan nama pengguna dan menampilkan pesan sapaan.

## Teknologi
- Python
- Flask
- HTML
- CSS

## Fitur
- Menampilkan halaman utama.
- Memasukkan nama pengguna melalui TextField.
- Mengirim data menggunakan method POST.
- Menampilkan pesan sapaan berdasarkan nama pengguna.

## Struktur Folder
```text
P.pertemuan 11/
├── static/
│   └── styles.css
├── templates/
│   └── index.html
├── app.py
└── README.md
```


## Cara Menjalankan

1. Aktifkan virtual environment:
   `.\.venv\Scripts\Activate.ps1`

2. Jalankan aplikasi Flask:
   `python -m flask --app app run --debug`

3. Buka browser pada alamat:
   `http://127.0.0.1:5000`
